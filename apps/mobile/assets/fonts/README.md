# Font Files

This directory should contain the following font files:

- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-SemiBold.ttf`
- `Inter-Bold.ttf`
- `JetBrainsMono-Regular.ttf`

## Download Instructions

1. **Inter**: Download from https://fonts.google.com/specimen/Inter
2. **JetBrains Mono**: Download from https://fonts.google.com/specimen/JetBrains+Mono

Place the `.ttf` files in this directory with the exact names listed above.
